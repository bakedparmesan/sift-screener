# Sift Screener

Swipe-based title and abstract screening for systematic reviews.

- Open an Excel (.xlsx/.xls) or CSV file and match the title, abstract and two decision columns.
- Swipe right = include (1), left = exclude (0), up = maybe (2). Keyboard: → ← ↑, Backspace for previous.
- Abstract screening shows only records included or marked maybe at title stage.
- Progress is saved on the device after every swipe, so you can close it and carry on later.
- Chrome or Edge on a computer: decisions are written straight into the Excel file in the background.
- Phone, Safari, Firefox: tap **Save Excel** to get the updated spreadsheet (on iPhone choose "Save to Files").

Everything runs in your browser. Your spreadsheet is never uploaded anywhere.
